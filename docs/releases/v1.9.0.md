## Changelog entry (already on `main`)

```
v1.9.0
Bulk share: pick multiple videos and multiple recipients at once, each pair gets its own private link, one email per recipient
Per-link view count and last-viewed time, plus real playback tracking (plays, furthest % watched, completed) from the video player
Bulk resend, bulk revoke, and bulk extend for selected links, each reporting per-item success/failure
Extend a link's expiry in place, including an already-lapsed-but-not-revoked link, without creating a new link
Bundles: a recipient with 2+ active links gets one consolidated listing page and one consolidated email instead of separate ones per link
```
